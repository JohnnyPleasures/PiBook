# PiBook Network Configuration

PiBook stores installed network configuration under:

    /etc/pibook-network/

No real Wi-Fi credentials or NetworkManager profile identifiers are
stored in the Git repository.

## config.json

Start from:

    config.example.json

The installed file contains:

- wireless interface
- hotspot SSID
- hotspot password
- hotspot address
- Wi-Fi channel
- country code
- fallback NetworkManager Wi-Fi profile UUID/name

The hotspot credentials and fallback profile identifiers are local to
each PiBook installation.

## startup.json

Start from:

    startup.example.json

The current startup coordinator requires a real saved NetworkManager
Wi-Fi profile as fallback.

Therefore `pibook-network-startup.service` must remain disabled until
`fallback_wifi_uuid` and `fallback_wifi_name` identify an existing
NetworkManager connection.

## watchdog.json

The repository version contains the validated PiBook watchdog defaults.

## dnsmasq.conf

This configuration provides DHCP and captive-portal DNS while PiBook is
operating as a hotspot.

## hostapd.conf

`hostapd.conf` is not stored in Git because it contains hotspot
credentials.

It is generated by `pibook-networkctl` from the installed
`config.json`.
